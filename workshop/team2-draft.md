(공지 주제 "미디어에 무엇이 남고 사라지는가"를 우리 프로젝트에 맞게 바꿨다.)

| 항목 | 내용 | 끝났다고 볼 기준 |
| --- | --- | --- |
| 새로 공부할 원리 | 소리를 주파수 조각(STFT)으로 나누고, 조각마다 "대상 목소리 몫"(마스크)을 정해 크기를 바꾸는 방법 | 마스크 값이 바뀌면 결과가 어떻게 변하는지 한 장으로 설명한다 |
| 우리 조에 먼저 써 볼 것 | 조절 강도를 바꿔 가며 대상 목소리와 주변 소리의 dB 변화를 잰다 | 강도 6단계의 표가 있다 (완료, 아래 4절) |
| 반 전체에 남길 것 | 각 조 자료에서 "줄이거나 키울 소리"와 "얼마나 남으면 충분한가" 한 줄 | 5개 조가 한 줄씩 적는다 |

## 4. 우리 조에서 잰 결과 (발표 3번)
발화와 환호를 섞은 통제 시험 한 건이다. 한국어와 실제 마이크는 확인하지 않았다.

| 강도 | 의미 | 대상 목소리 | 주변 소리 |
| ---: | --- | ---: | ---: |
| 1 | 최대로 줄임 | −25.1 dB | −1.0 dB |
| 0.5 | 절반 | −5.6 dB | −0.5 dB |
| 0 | 그대로 | 0 dB | 0 dB |
| −1 | 키움 | +5.8 dB | +0.9 dB |
| −2 | 더 키움 | +9.2 dB | +1.7 dB |
| −4 | 최대 | +13.6 dB | +3.1 dB |

읽는 법:
- 최대로 줄여도 0이 되지 않고 −25 dB까지다. 남는 양이 있다.
- 키우면 대상 목소리만 커지지 않고 주변 소리도 같이 커진다. 대상과 주변 소리를 완전히 가르지 못해서로 보이나 원인은 확인하지 않았다.
- 이 수치는 사람이 알아듣는 정도가 아니다.

## 5. 워크숍 (15분)

준비: 폰, 이어폰 또는 스피커. 설치와 AI 계정은 필요 없다.
음원: 같은 10초 구간의 4가지 버전. `A 줄임`, `B 원본`, `C 키움1`, `D 키움2`.
(음원은 공개 영상의 일부이다. **나눠 주지 않고 화면과 스피커로만 틀어 준다.**)

1. (3분) 4가지를 한 번씩 듣는다. 어느 쪽이 원본인지 각자 적고 맞혀 본다.
2. (3분) 2조가 4절의 표를 보여 주고, A와 D에서 "무엇이 남고 무엇이 같이 변했는가"를 말한다.
3. (6분) 각 조가 아래 양식을 한 줄씩 채운다.
4. (3분) 옆 조와 바꿔 읽고, 빠진 소리가 있으면 짚어 준다.

**양식 (복사해서 쓰기)**

| 질문 | 우리 조 답 |
| --- | --- |
| 우리 자료에서 줄이고 싶은 소리 | |
| 우리 자료에서 키우고 싶은 소리 | |
| 그 소리를 바꿀 때 같이 바뀌면 안 되는 소리 | |
| 얼마나 남으면(또는 커지면) 충분한가 | |
| 그 기준은 어떻게 정했는가 | |

끝나면 각 조가 가져가는 것: 우리 자료에서 크기를 바꿀 소리, 같이 지켜야 할 소리, 충분하다고 볼 기준.
