## 2. 이번 주제로 얻을 것

주제: **특정 목소리 크기 조절: 줄이면 얼마나 남고, 키우면 무엇이 같이 변하는가**
(공지 주제 "미디어에 무엇이 남고 사라지는가"를 우리 프로젝트에 맞게 바꿨다.)

| 항목 | 내용 | 끝났다고 볼 기준 |
| --- | --- | --- |
| 새로 공부할 원리 ① STFT와 마스크 | 소리를 짧은 시간 조각과 주파수 조각으로 나누고, 조각마다 "대상 목소리 몫"(0~1)을 곱해 크기를 바꾼다. | 몫을 날카롭게 하는 값(p)을 바꾸면 결과가 어떻게 변하는지 4절 표로 설명한다 |
| 새로 공부할 원리 ② 화자 임베딩 | 목소리의 특징을 숫자로 만든다. 기준 목소리 5~10초로 "이 사람"을 정하고, 섞인 소리에서 그 사람 몫을 찾는다. (5조 주제와 같은 원리) | 기준 구간이 길거나 깨끗할 때와 아닐 때의 차이를 한 문장으로 말한다 |
| 새로 공부할 원리 ③ dB와 성분별 측정 | 대상과 주변 소리가 각각 얼마나 변했는지 따로 계산한다. (1조 주제와 이어지는 잣대) | 대상과 주변 소리의 dB 변화를 같은 표에 둔다 |
| 우리 조에 먼저 써 볼 것 | 조절 강도와 마스크 날카로움(p)을 바꿔 가며 dB 변화를 잰다 | 강도 6단계 표와 p 5단계 표가 있다 (완료, 4절) |
| 반 전체에 남길 것 | 각 조 자료에서 "줄이거나 키울 소리"와 "얼마나 남으면 충분한가" 한 줄 | 5개 조가 한 줄씩 적는다 |

## 4. 우리 조에서 잰 결과 (발표 3번)
발화와 환호를 섞은 통제 시험 한 건이다. 한국어와 실제 마이크는 확인하지 않았다.

| 강도 | 의미 | 대상 목소리 | 주변 소리 |
| ---: | --- | ---: | ---: |
| 1 | 최대로 줄임 | −25.1 dB | −1.0 dB |
| 0.5 | 절반 | −5.6 dB | −0.5 dB |
| 0 | 그대로 | 0 dB | 0 dB |
| −1 | 키움 | +5.8 dB | +0.9 dB |
| −2 | 더 키움 | +9.2 dB | +1.7 dB |
| −4 | 최대 | +13.6 dB | +3.1 dB |

읽는 법:
- 최대로 줄여도 0이 되지 않고 −25 dB까지다. 남는 양이 있다.
- 키우면 대상 목소리만 커지지 않고 주변 소리도 같이 커진다. 대상과 주변 소리를 완전히 가르지 못해서로 보이나 원인은 확인하지 않았다.
- 이 수치는 사람이 알아듣는 정도가 아니다.

**마스크 날카로움(p)을 바꾼 결과** (줄이기 최대, 같은 시험. 값이 클수록 대상/주변 구분을 더 날카롭게 한다)

| p | 대상 목소리 | 주변 소리 |
| ---: | ---: | ---: |
| 1 | −13.65 dB | −1.86 dB |
| 2 | −20.75 dB | −1.20 dB |
| 4 | −24.80 dB | −0.92 dB |
| 8 | −25.04 dB | −0.84 dB |

p를 4에서 8로 올려도 더 줄어드는 양이 작아서 4를 쓴다. (출처: 위키 "스티브 잡스 발표 억제 실험")

## 5. 워크숍 (15분)

준비: 폰, 이어폰 또는 스피커. 설치와 AI 계정은 필요 없다.
- **미리 만든 음원 4개**(같은 10초 구간): `A 줄임`, `B 원본`, `C 키움1`, `D 키움2`. 반 전체가 폰으로 듣는다.
- **앱** `vk.leonamin.com`: 서버가 한 번에 한 요청만 처리하므로 2조가 화면으로 시연한다. 각 조는 직접 돌리지 않아도 된다.
- 음원은 공개 영상의 일부이다. **나눠 주지 않고 화면과 스피커로만 틀어 준다.**

1. (3분) 4가지를 한 번씩 듣고 어느 쪽이 원본인지 맞혀 본다.
2. (3분) 2조가 앱에서 슬라이더를 움직여 보여 주고, 4절 표로 "무엇이 남고 무엇이 같이 변했는가"를 말한다.
3. (6분) 각 조가 아래 양식을 한 줄씩 채운다.
4. (3분) 옆 조와 바꿔 읽고, 빠진 소리가 있으면 짚어 준다. 끝나면 각 조가 설계 ⑧에 적기 시작한다.

**양식 (복사해서 쓰기)**

| 질문 | 우리 조 답 |
| --- | --- |
| 우리 자료에서 줄이고 싶은 소리 | |
| 우리 자료에서 키우고 싶은 소리 | |
| 그 소리를 바꿀 때 같이 바뀌면 안 되는 소리 | |
| 얼마나 남으면(또는 커지면) 충분한가 | |
| 그 기준은 어떻게 정했는가 | |

끝나면 각 조가 가져가는 것: 설계 ④(잣대와 목표) 칸에 쓸 문장. 우리 자료에서 크기를 바꿀 소리, 같이 지켜야 할 소리, 충분하다고 볼 기준.
