# PoC 및 평가 계획

> 2026-09-30 갱신: 아래 초기 기획은 이력으로 보존한다. 현재 잡스 발표의 REAL-TSE 파일 변환과 실험을 수행했으며, 최신 상태는 [실험 기록](../references/jobs-experiment.md)을 따른다.


## 첫 실험

1. 후보 저장소의 설치 방법, 체크포인트, 라이선스, 등록 음성 입력 지원을 확인한다.
2. `enrollment.wav`와 `mixture.wav`의 샘플레이트·채널·정규화 요구를 확인한다.
3. 사전학습 모델로 대상 성분을 추정하고 `filtered.wav`를 만든다.
4. 원본과 결과를 같은 조건에서 청취하고 실측값을 기록한다.

코드·모델 다운로드나 추론은 아직 수행하지 않았다.

## 비교 조건

대상 단독, 비대상 단독, 번갈아 발화, 동시발화, 잡음·반향 조건을 구분한다. 등록 음성과 평가 발화는 분리해 구성한다. 동일 입력에서 무처리, 구간 감쇠, TSE subtraction, 마스킹을 비교한다.

## 평가안 — 수치 기준 미확정

| 항목 | 제안 측정 | 주의점 |
| --- | --- | --- |
| 대상 명료도 | 청취자의 단어·문장 인식률 전후 비교 | 낮아지는 것이 목표 |
| 비대상 명료도 | 같은 방식의 전후 비교 | 전체 음소거를 성공으로 판정하지 않음 |
| 오탐·미탐 | 비대상 억제 및 대상 통과 사례 기록 | 화자·조건별 구분 |
| 출력 품질 | 왜곡·잔향·환경음 손상 청취 기록 | 허용 수준은 실험 후 합의 |
| 처리 시간 | 오디오 길이 대비 전체 처리 시간 | 실시간 지연과 구분 |

ASR 오류율은 보조 지표 후보이며 사람의 청취 명료도와 동일한 것으로 보지 않는다. 합격 임계값은 미정이다.

## 실시간 확장

오프라인 결과 확인 후 마이크 → 버퍼 → 추론 → 재구성 → 헤드폰 경로를 검토한다. 추론 시간뿐 아니라 오디오 I/O와 버퍼링을 포함한 종단 지연을 측정해야 한다. 실시간 구현은 현재 완료 범위가 아니다.
