# 프로젝트 및 위키 초기화

사용자가 지정한 `~/dev/voice-killer`에 독립 프로젝트를 초기화했다. 사용자 제공 대화를 요구사항, 구현 후보, ADR, 연구 후보와 PoC 평가 계획으로 정리했다.

기본 concepts/decisions/references/logs 구조, 디렉터리별 index.md, `.agents/wiki-path`와 `.agents/wiki-structure.md`를 구성했다. 음성·모델·결과물과 비밀 값의 Git 제외 규칙을 추가했다.

이번 작업은 문서와 Git 초기화이며 모델 실행, 연구 원문 검증, 원격 저장소 생성 및 배포를 포함하지 않는다.
