# 페이지 전체 드래그드롭과 음량 숫자 고정

- 구현: 원본 오디오 화면과 기준 목소리 화면(다른 파일 모드)에서 창 전체가 드롭 대상이다. 끄는 동안 화면 전체에 점선 테두리와 "원본 오디오로 올리기" 같은 대상 이름이 뜬다. 파일이 없을 때는 패널 안에 큰 드롭 영역(`vk-drop`)이 보인다.
- 구현: 음량 `%` 숫자(`output`)에 `min-width: 5ch`를 주어 5%↔100% 전환에도 슬라이더가 움직이지 않는다.
- 확인: 헤드리스 Chromium에서 합성 `DragEvent`로 확인했다. 사이드바에 놓은 파일이 원본으로 들어가 파형이 나왔고, 음량 0·5·100·300%에서 슬라이더 x 좌표가 같았다.
- 한계: 실제 OS 파일 드래그와 기준 목소리 화면은 직접 확인하지 않았다. 오디오·영상이 아닌 파일을 놓으면 파형 오류 알림이 뜬다.
