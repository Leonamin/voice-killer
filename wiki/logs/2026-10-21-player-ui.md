# 오디오 플레이어 UI 개선

- 구현: `Waveform`에 재생·일시정지 고정 너비 버튼, `분:초.밀리초` 재생 위치, 음량 0~300% 슬라이더를 추가했다. 100%를 넘는 음량은 `<audio>` 대신 Web Audio `GainNode`로 증폭한다.
- 구현: 추출·제거·변환 결과를 기본 `<audio controls>` 대신 같은 `Waveform`(구간 선택 없음, `kind="result"`)으로 보여 준다. 다운로드 버튼은 따로 둔다.
- 확인: 프로덕션 빌드에서 원본 오디오 화면의 재생 위치 갱신, 버튼 너비 유지, 음량 슬라이더 값 반영을 확인했다. 제거 결과 화면에서 A/B 전환과 파형 재생 위치가 동작했다.
- 한계: 원본(A)은 숨은 `<audio>`로 재생하므로 A 재생 중에는 파형 커서가 움직이지 않고 음량 슬라이더도 적용되지 않는다. 음량 증폭으로 실제 소리가 커지는지는 귀로 확인하지 않았다. 변환 결과 화면은 직접 확인하지 않았다.
- 알려진 문제: `vite dev`(React StrictMode)에서는 파일을 올리면 "Failed to fetch" 파형 오류가 뜬다. 이번 변경 전에도 같았고 프로덕션 빌드에서는 나오지 않았다.
- 갱신: 사용법 페이지(`web/src/Help.tsx`)와 스크린샷 03·04·07.
