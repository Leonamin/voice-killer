# 조절 강도별 실측

`scripts/evaluate_gain.py`로 측정했다. 조건은 [잡스 억제 실험](jobs-experiment.md)의 통제 시험과 같다. 발화 39.8~48.6초와 관중 49.5~58.3초를 RMS 0.08로 맞춰 겹쳤고, mask p=4에 q>=0.65 완전 차단을 적용했다. 성분 gain은 두 정답 성분에 대한 공동 최소제곱 값이다. 사람의 이해도 점수가 아니다. 결과 파일은 Git 밖의 `outputs/gain/`에 있다.

| strength | 의미 | 발화 gain | 관중 gain | 출력 peak |
| ---: | --- | ---: | ---: | ---: |
| 1 | 최대로 줄임 | −25.12 dB | −0.98 dB | 1.80 |
| 0.5 | 절반 | −5.55 dB | −0.48 dB | 1.75 |
| 0 | 그대로 | 0.00 dB | 0.00 dB | 1.71 |
| −1 | 키움 | +5.78 dB | +0.88 dB | 1.87 |
| −2 | 더 키움 | +9.22 dB | +1.68 dB | 2.79 |
| −4 | 최대 | +13.59 dB | +3.08 dB | 4.63 |

## 해석과 한계

- 키울 때 관중 소리도 같이 커진다(최대 +3.08 dB). 마스크가 대상과 주변 소리를 완전히 가르지 못하기 때문으로 보이나 원인 분석은 하지 않았다.
- peak가 1을 넘는다. 16비트 wav로 저장하면 깨진다. 이 시험은 float wav로 저장했다. 이 시험의 입력 자체가 이미 peak 1.7이다.
- 단일 입력 한 건의 결과다. 한국어, 다른 화자, 실제 마이크는 검증하지 않았다.
- 키우기를 들었을 때 자연스러운지는 청취 평가를 하지 않았다.
