# 대화 출처와 미확인 사항

## 출처

사용자가 2026-09-30 제공한 `Conversation Snapshot` 텍스트를 요약했다. 원문은 별도 원본 보관이나 전체 복제 없이 주제별 문서로 정리했다.

## 보존한 구분

- 요구·결정: 특정 화자 억제, 완벽한 제거 불필요, 고정 파형 ANC 제외.
- 대화에서 보고된 사실: 교수의 진행 허가, 관련 연구·구현 후보 조사.
- 미검증 가정: 한국어·강의실 일반화, 음성 샘플 확보, 등록 음성 길이, 지연.
- 아직 없는 결과: 모델 설치, 실제 추론, 방식별 비교, 정량 평가.

원문의 “Confirmed” 표기는 이전 대화의 분류이며 이번 작업에서 독립 검증한 결과를 뜻하지 않는다. 완벽한 제거보다 억제가 쉽다는 전망도 실제 구현 난이도에 대한 보장은 아니다.

## 누락된 근거

원문이 언급한 2026년 2학기 강의계획서 자체는 첨부에 포함되지 않았다. 내부 참조 표기만 있어 세부 과제 기준은 확정하지 않았다. 원래 대화의 날짜와 교수 피드백 원문도 확인하지 않았다.
