# 스티브 잡스 발표 억제 실험

## 출처와 모델

- 음원: [2007 첫 아이폰 소개 발췌](https://www.youtube.com/watch?v=MnrJzXM7a6o), 619.1485초, 48 kHz stereo. 2007년 발표의 공개 재게시 영상이며 전체 행사는 아니다.
- 모델: [REAL-TSE 공식 baseline](https://github.com/REAL-TSE/wesep-real-tse), revision `2a540977a348fbaa92e623210505430e2cec608d`, 공식 링크에서 받은 `spk_emb_100`.
- 인코더: [WeSpeaker](https://github.com/wenet-e2e/wespeaker/tree/8f53b6485d9f88a207bd17e7f8dba899495ec794), ECAPA_TDNN_GLOB_c512.
- [WeSep 현재 안내](https://github.com/wenet-e2e/wesep): 본 저장소의 공식 모델 패키지·CLI는 확인 시점에 준비 중이었다.
- [SAM Audio](https://github.com/facebookresearch/sam-audio)는 모델 접근 신청을 요구하므로 이번 경로에서는 실행하지 않았다.

모델과 소스 해시는 프로젝트 `model-provenance.json`, 원본과 등록 음성 해시는 `data/source-manifest.json`, 결과 해시는 각 출력 JSON에 있다. 위 결과는 코드 존재 확인이 아니라 실제 추론 결과다.

## 구간

등록 음성은 12.4~19.4초다. 자연 평가 구간 38~68초, 132~202초와 분리했다. 발표 중 같은 사람이라는 가정 아래 선택했다. 전체 파일 변환에는 등록 구간도 포함되지만 이를 독립 성능 증거로 사용하지 않는다.

## 1차 자연 음원 결과 (p=4, hard 보정 전)

| 구간 | 역할 | RMS 변화 | 원본과 상관 |
| --- | --- | ---: | ---: |
| 40~48초 | 발화 중심 | −28.89 dB | 0.090 |
| 50~58초 | 박수 중심 | −0.05 dB | 0.999 |
| 132~144초 | 발화 중심 | −23.12 dB | 0.107 |
| 156~169초 | 자연 동시발화·관중 반응 후보 | −3.42 dB | 0.710 |
| 177~180초 | 큰 환호와 발화 잔향 | −7.20 dB | 0.546 |
| 189~194초 | 관중 웃음 중심 | −0.42 dB | 0.973 |

자연 혼합 음원에는 분리된 정답이 없어 RMS 변화만으로 각 화자·박수의 감소량을 분해할 수 없다. 177~180초는 보존 성능이 부족한 구간으로 명시한다. 구간 라벨은 전사와 시간 배치를 바탕으로 한 연구용 구분이며 수동 청취 판정 완료를 뜻하지 않는다.

## 통제된 동시 소리 시험

발화 39.8~48.6초와 박수 49.5~58.3초를 각각 RMS 0.08로 맞춰 겹쳤다. 입력 음량 조정은 이 통제 시험에만 해당한다. 각 성분에는 원래 녹음의 방음·잔향이 남아 있어 완전한 studio stem은 아니다.

| 방식 | 발화 성분 gain | 관중 성분 gain | 출력과 관중 성분의 오차 SNR |
| --- | ---: | ---: | ---: |
| 직접 subtraction | −15.11 dB | −1.79 dB | 7.24 dB |
| 마스크 p=1 | −13.65 dB | −1.86 dB | 8.30 dB |
| 마스크 p=2 | −20.75 dB | −1.20 dB | 9.26 dB |
| 마스크 p=4 | −24.80 dB | −0.92 dB | 9.22 dB |
| 마스크 p=8 | −25.04 dB | −0.84 dB | 9.09 dB |
| **최종 p=4 + q>=0.65 완전 차단** | **−25.08 dB** | **−0.93 dB** | **9.18 dB** |

성분 gain은 두 정답 성분에 대한 공동 최소제곱 투영 값이며 사람의 이해도 점수가 아니다. p=4 관중 단독 입력의 전체 RMS 변화는 −0.50 dB였다. p=8의 추가 억제 이득이 작아 p=4를 선택했다. 이후 발화 잔류 개선용 hard 보정을 추가해도 관중 보존 지표가 크게 변하지 않았다.

## 발화 잔류 확인

로컬 faster-whisper base.en, CPU int8, beam=3, 영어, `condition_on_previous_text=False`로 같은 구간을 비교했다. 약한 마스크와 subtraction은 원래 발화 문장 상당 부분을 재인식했다. 정규화 비율 p=4 결과에서는 두 자연 시험 구간의 원래 발표 문장이 대부분 인식되지 않았고, 짧은 감사 문구 같은 무관한 전사가 나타났다.

이는 ASR의 무음·잡음 환각도 포함하므로 인식 문구가 실제로 들린다거나 사람이 못 알아듣는다고 단정할 수 없다. 청취용 A/B 파일을 함께 제공한다. 초기 고차 마스크의 수치 오류는 수정했으며 `*-stable-p4.wav`는 수치 보정 후 soft-only 결과다. 아래 최종 결과는 여기에 대상 우세 bin 완전 차단까지 적용했다.

## 긴 음원에서 발견한 잔류와 최종 보정

1차 전체 변환의 250~270초, 420~440초, 580~600초는 RMS가 각각 약 46, 40, 44 dB 감소했지만 독립적인 ASR 입력으로 주었을 때 원래 발화가 상당 부분 전사됐다. 따라서 짧은 환호 포함 구간의 전사 결과만으로 전체 억제 성공을 판단하지 않았다.

모델이 대상 우세로 판단한 `q>=0.65` bin을 완전히 차단하는 보정을 추가했다. 같은 세 구간의 별도 시험에서 처음 두 구간은 전사 없음, 마지막은 구두점만 남았다. 이는 인간 청취나 음성 복원 불가능성의 증명이 아니다. 관중 소리와 겹친 혼합 시험에서는 발화 성분 −25.08 dB, 관중 성분 −0.93 dB로 측정됐다.

ASR 버전, 디코딩과 낮은 신호의 정밀한 차이에 따라 무관한 문구가 바뀌는 현상을 관찰했다. 전사 길이를 곧 성공률로 해석하지 않는다.

## 파일 위치

프로젝트 기준:

- `outputs/pilot-core.original.wav`, `outputs/pilot-core-stable-p4.wav`: 38~68초 비교
- `outputs/reveal-final.original.wav`, `outputs/reveal-final.wav`: 최종 132~202초 비교
- `outputs/controlled/`: 알려진 성분으로 구성한 단독·동시 시험
- `outputs/iphone-2007-final.*`: 전체 파일 변환 결과와 메타데이터
- `outputs/stream-v2/`: 실제 시간 속도 PCM 스트림 결과
- `outputs/stable-mask-asr.json`, `outputs/controlled/metrics.json`, `outputs/natural-interval-metrics.json`: 보조 평가 원시 결과

## 한계와 후속 검증

큰 환호·비명, 다른 사람이 동시에 말하는 경우, 한국어, 실제 강의실과 마이크 입력은 추가 검증이 필요하다. 이번 목표의 파일 출력과 관중 소리 보존은 실제 결과를 제공하지만, 완벽한 제거·모든 환호 보존 또는 실시간 이어폰 성능을 주장하지 않는다. 데이터·가중치는 Git 밖에 보관한다. 코드 헤더의 Apache-2.0 표기와 별개로 가중치 재배포 조건은 별도로 확인해야 한다.

## 최종 실행 검증

- 전체 출력: 619.1485초, 9,906,376샘플, 16 kHz 모노. 총 처리 시간 202.37초(RTF 0.327).
- 최종 실시간 속도 파일 스트림: 70초, 35개 2초 블록, 총 71.45초. 블록 계산 평균 1.39초, 최대 1.65초로 모든 블록이 2초 입력 주기보다 빨랐다. 지연은 대략 2초 버퍼 + 계산 시간이며 하드웨어 I/O 지연은 포함하지 않는다.
- 계산 시간은 로컬 M4 Max CPU에서 측정했으며 일부 실험이 동시에 실행됐다. 전용 벤치마크 점수는 아니다.
- 전체 결과의 원본·대상 추정·처리본 SHA-256과 샘플 수·유한값을 검사했다. 스트림 출력도 1,120,000샘플로 입력 길이와 일치했다.
- 별도 최소 의존성 가상환경에서 실제 추론과 14개 테스트 통과. README의 setup.sh 명령 재실행 통과.
- 청취용 `outputs/demo-before.wav`, `outputs/demo-after.wav`는 최종 70초 결과를 음량 변경 없이 PCM16으로 저장한 호환 복사본이다.

최종 전체 파일을 다시 잘라 동일 ASR로 검사한 결과 250~270초는 전사가 없었고, 420~440초와 580~600초에는 원래 발표와 다른 문구가 나왔다. 최종 70초 오프라인·스트리밍 결과에서도 원래 발표 문장을 재현하지 못하고 짧거나 반복되는 무관한 문구가 나타났다. 원시 결과는 `outputs/final-v2-asr.json`에 남겼다. 특정 설정의 ASR 관찰이며 모든 발화의 인간 명료도 검사를 대체하지 않는다.
