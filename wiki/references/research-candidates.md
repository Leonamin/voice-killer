# 선행 연구 후보

> 2026-09-30 갱신: 아래 초기 기획은 이력으로 보존한다. 현재 잡스 발표의 REAL-TSE 파일 변환과 실험을 수행했으며, 최신 상태는 [실험 기록](../references/jobs-experiment.md)을 따른다.


아래 목록과 설명은 사용자 제공 대화에서 이관했다. 이번 초기화에서는 링크 원문, 체크포인트 제공 여부, 라이선스, 설치 가능성이나 성능을 재검증하지 않았다.

| 후보 | 대화에서의 위치 | 원문 후보 |
| --- | --- | --- |
| VoiceFilter | 화자 조건부 스펙트로그램 마스킹 | [Google Research](https://research.google/pubs/voicefilter-targeted-voice-separation-by-speaker-conditioned-spectrogram-masking/) |
| VoiceFilter-Lite | 스트리밍·기기 내 처리 참고 | [Google Research](https://research.google/pubs/voicefilter-lite-streaming-targeted-voice-separation-for-on-device-speech-recognition/) |
| SpEx | 시간 영역 화자 추출 | [논문](https://arxiv.org/abs/2004.08326) |
| WeSep | 실행 후보 툴킷 | [GitHub](https://github.com/wenet-e2e/WeSep) |
| REAL-TSE / WeSep | 실제 환경 실험 후보 | [GitHub](https://github.com/REAL-TSE/wesep-real-tse) |

다음 조사에서는 논문 존재와 실행 가능한 사전학습 모델 제공을 구분하고, 직접 등록 음성을 넣을 수 있는지 확인한다.
