# ADR 003: 웹 데모 범위와 엔진·웹 책임 분리

## Status

Accepted — 2026-10-14 사용자 요구.

## Context

팀 과제의 최종 시연을 웹사이트로 보여 준다. 사용자가 요구한 기능은 특정 인물 음성 추출, 제거, 음성 변환, 실시간 제거다. 음성 변환의 대상은 고정 인물이 아니라 사용자가 넣는 참조 음원 A의 목소리다. 시연 장비는 Ryzen 7 8745HS CPU 전용 PC다.

## Decision

1. 엔진은 음성 처리(추출·제거·변환·스트림 처리)만 담당한다.
2. 웹은 편의 기능(자르기, 구간 선택, 녹음, 재생, 비교)과 엔진 호출만 담당한다.
3. 음성 변환은 참조 음원만으로 동작하는 zero-shot VC로 한다. 모델은 [로드맵](../concepts/roadmap.md) 트랙 D의 스파이크 결과로 정한다.
4. 웹은 FastAPI와 단일 HTML로 만들고 `localhost`에서만 실행한다. 외부 배포는 하지 않는다.
5. 실시간 제거는 블록 단위 준실시간으로 표현하고, 종단 지연 실측값을 함께 제시한다.

## Consequences

트랙 사이의 경계는 로드맵의 인터페이스 계약 하나로 고정되어 병렬 작업이 가능하다. CPU 전용 장비라 실시간 VC는 확장 목표로만 둔다. 실존 인물 목소리로 변환한 결과는 화면에 합성 음성으로 표시하고, Git이나 공개 채널에 올리지 않는다.
